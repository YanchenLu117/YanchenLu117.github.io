A digital garden is not a feed. It is a place where ideas are allowed to remain unfinished, to be revised, and to accumulate context over time. This site follows that logic: the writing is intentionally quiet, and the margin is treated as part of the argument rather than as leftover space.

The margin is not a container for decoration.<Sidenote>On wide screens, a sidenote moves into the right margin with a small reference number. Below the tablet breakpoint it falls back into the flow with a hairline rule.</Sidenote> It is a second column of thought, set in a smaller size and a quieter color. A second note can follow the same pattern.<Sidenote>Growth stages — Seedling, Budding, Evergreen — are metadata, not decoration. They tell a reader how much confidence to place in the current version of a note.</Sidenote>

## A living note

Long-form reading calls for a different measure from the rest of the interface. The body here is set in a serif face, with a narrow column and generous leading; the interface stays in a cleaner sans and mono. Links are underlined with a single hairline, and emphasis is oxblood rather than a second accent color.

- The text measure stays near 600 pixels.
- Sidenotes occupy the remaining margin on wide screens.
- On mobile, they return to the flow as a bordered aside.

This note is a small demonstration of the system. It can be revised, promoted to Evergreen, or replaced with a research note when the next idea is ready.
